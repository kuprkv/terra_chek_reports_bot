# Telegram Бот для проверки отчётов и домашних заданий

Бот проверяет наличие сообщений с хэштегами в указанных ветках за вчерашний день и выдаёт результат с ссылками на сообщения.

## Возможности
- Поддержка двух независимых веток: для отчётов и для ДЗ.
- Поиск сообщений за вчерашний день.
- Вывод ссылок на найденные сообщения.
- Работает в группах с темами (Topics).

## Команды
- `/start` – приветствие и справка.
- `/set_reports_topic <название>` – задать ветку для отчётов.
- `/set_homework_topic <название>` – задать ветку для ДЗ.
- `/check_reports #хэштег1 #хэштег2 ...` – проверить отчёты.
- `/check_homework #хэштег1 #хэштег2 ...` – проверить ДЗ.
